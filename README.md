# COG300 Labs

Shared workspace for our COG300 group labs throughout the term.

## Structure

- `labs/`: one folder per course lab, starting with [Lab 3: Build your own bot](labs/lab-03/).
- `templates/lab/`: copy this folder when starting a lab.
- `docs/`: team agreements, meeting notes, and shared references.

Use stable folder names (`lab-03`, `lab-04`, …) and put each lab's descriptive title in its README. This keeps the repository useful as topics change.

## Start a lab

Copy `templates/lab/` into `labs/lab-03/` (match the assigned course lab number), then fill in its README. Add folders such as `src/`, `analysis/`, or `figures/` only when needed.

## Collaborate

1. Create an issue for a task and assign an owner.
2. Create a branch such as `lab-03/literature-review` or `docs/team-notes`.
3. Make focused commits and open a pull request into `main`.
4. Ask a teammate to review before merging.
5. Record the final submission location in the lab's README.

See [CONTRIBUTING.md](CONTRIBUTING.md) for naming and workflow conventions.
