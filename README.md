# COG300 Group Projects

Shared workspace for our COG300 group projects throughout the term.

## Structure

- `projects/`: one numbered folder per project, starting with `project-01`.
- `templates/project/`: copy this folder when starting a project.
- `docs/`: team agreements, meeting notes, and shared references.

Use stable folder names (`project-01`, `project-02`, …) and put each project's descriptive title in its README. This keeps the repository useful as topics change.

## Start a project

Copy `templates/project/` into `projects/project-01/` (use the next available number), then fill in its README. Add folders such as `src/`, `analysis/`, or `figures/` only when needed.

## Collaborate

1. Create an issue for a task and assign an owner.
2. Create a branch such as `project-01/literature-review` or `docs/team-notes`.
3. Make focused commits and open a pull request into `main`.
4. Ask a teammate to review before merging.
5. Record the final submission location in the project's README.

See [CONTRIBUTING.md](CONTRIBUTING.md) for naming and workflow conventions.
